# PB626 Plus ELAN/eMMC — заводская цепочка загрузки

**Статус:** статическая реконструкция по заводскому дампу первых 68 МиБ eMMC
и архиву системы. Контрольные суммы eGON и файлы FAT проверены. Это
спецификация штатной цепочки, а не доказательство запуска Megi 7.2 из eMMC.
Все адреса RAM физические; верхние границы диапазонов исключительные.
BootROM не извлечён; его начальный путь восстановлен по структуре носителя.

## Носитель

eMMC Samsung 8WPD3R, 512 байт/сектор, 256 МиБ DRAM (0x40000000–0x50000000).
Аппаратные eMMC boot0/boot1 полностью нулевые; PARTITION_CONFIG=0.
Настоящие eGON-загрузчики находятся в **User Area**, а не в аппаратных boot-разделах.

| Объект | LBA | Смещение в eMMC | Размер |
|---|---:|---|---:|
| MBR / EBR | 0 / 1–6 | 0x00000000 / 0x200–0xc00 | 512 байт на сектор |
| eGON.BT0 | 16–57 | 0x00002000 | 0x5400 |
| eGON.BT1 | 38192–38639 | 0x012a6000 | 0x38000 |
| Идентичная копия BT1 | 38704–39151 | 0x012e6000 | 0x38000 |
| p2, FAT16 | 73728–139263 | 0x02400000 | 32 МиБ |
| p7, stock root | 204800–275455 | 0x06400000 | 70656 секторов |
| p8, stock applications | 275456–776191 | 0x08680000 | 500736 секторов |
| p1, stock user data | 1009664–15269887 | 0x1ed00000 | 14260224 секторов |

BT0 checksum 0x9cc6b83a; BT1 checksum 0xdf3154dc. Обе суммы проверены.
Использование дубликата BT1 при ошибке не доказано.

## Последовательность

1. **BootROM → BT0.** BootROM получает BT0 из User Area (LBA 16) в SRAM.
   BT0 начинает с ветвления на 0x02c8, настраивает CPU и стек 0x8000.
   Параметры DRAM — блок 80 байт по 0x38: DDR3, 408 МГц, rank 1,
   I/O 16, bus 16, CAS 9, 256 МиБ; TPR0=0x42d899b7,
   TPR1=0xa090, TPR2=0x22a00.
2. **BT0 → BT1.** Код 0x0388–0x0524 читает заголовок с LBA 38192,
   затем 448 секторов в 0x42400000 и проверяет checksum. Завершает MMC,
   выключает MMU/кэши, переносит актуальные DRAM-параметры из 0x38
   в 0x4240004c (80 байт) и переходит к BT1 (0x088c).
   Дисковый заголовок BT1 указывает 512 МиБ, но BT0 обновляет его в RAM.
3. **BT1 → boot.axf.** BT1 начинает по 0x42400000 (ветвление 0x424082d0).
   Устанавливает стеки SVC=0x42600000, IRQ=0x42680000,
   SYS=0x42700000; копирует векторы в SRAM 0x0–0x84 и подпрограммы
   в 0x400–0x7c58; таблица MMU 0x8000–0xc000.
   Область распределителя 0x43600000–0x44600000.
   Инициализирует хранилище и FAT, читает c:\script.bin
   (fallback c:\script0.bin) в 0x42f00000. Затем загружает c:\boot.axf,
   размещает ELF-секции и вызывает указатель eGon2app BootMain 0x428005f4
   (не ELF e_entry 0x428001c4). ELF RAM 0x42800000–0x428051c0.
4. **boot.axf → payload.** BootMain выбирает linux.ini или recovery.ini.
   Нормальная конфигурация читает c:\linux\bImage в 0x40008000,
   максимум 0x800000 байт. Функция 0x42800420 читает описанные сегменты.
   img_base — адрес загрузки, kernel_base — независимый адрес исполнения,
   по умолчанию 0x40008000. para_base по умолчанию 0x40000100.
   Функция 0x42800314 записывает ATAG_CORE, CMDLINE, NONE.
   Затем memcpy (вызов 0x42800584) копирует 0x10000 байт из
   0x42f00000 в 0x43000000. Вызов 0x4280473c: SVC #6.
5. **BT1 SVC #6 → ядро.** Вектор 0x08 → 0x42424120 →
   0x424223b0 → диспетчер 0x4240bdac → case 6 0x4240c16c →
   функция 0x4240d960. Останавливает storage, DMA, таймеры, LRADC,
   контроллер прерываний, маскирует IRQ/FIQ и отключает MMU/D/I-cache.
   Последний переход: BLX r3, 0x4240d9c4. На нормальном пути
   r0=0, r1=0xda7, r2=0x40000100, r3=PC=0x40008000,
   CPU в привилегированном System mode. Заводской Image затем сам
   устанавливает r0=0, r1=0xda8, r2=0x40000000 и CPSR_c=0xd3 (SVC).
6. **Linux 3.0.8 → stock userspace.** Заводское ядро — несжатый Image.
   Нормальная INI передаёт root=/dev/mmcblk0p7 init=/init rootwait.
   rcS монтирует p2 (/boot), p8 (/ebrmain), p9 (/mnt/secure),
   загружает драйверы и запускает /ebrmain/pocketbook.

## Следствия для порта

* **Сохранять BT0/BT1/boot.axf, MBR/EBR, аппаратные boot0/boot1,
  script и калибровку.** Новый payload — обычный файл на p2.
* Нельзя загружать современный zImage средствами AXF в 0x42000000:
  исследованный zImage 7602960 байт занимает 0x42000000–0x42740310
  и перекрывает исполняющийся BT1 и его стеки до SVC #6.
  При FEL этого BT1 нет. Коллизия подтверждена; она не объясняет
  автоматически все варианты копирования после SVC.
* Предпочтительный следующий опыт — один образ по штатному 0x40008000
  (не больше 8 МиБ), минимальная невозвращающаяся ARM-обёртка,
  собственный стек, явная передача DTB, проверенная карта RAM
  с учётом распаковки ядра. Полноценный промежуточный U-Boot не обязателен.
  Окончательные адреса назначения выбираются по размерам конкретной сборки.
* Файловая система Alpine на eMMC p1 уже проверена через FEL;
  штатная загрузка не доказана. В старом main-установщике используется p8,
  а часть U-Boot-экспериментов ожидает p1. Не смешивать эти схемы.
* Маркер до перехода в ядро не является доказательством входа в него.
  Нужны отдельные подтверждения входа, распаковки, PID 1 и запуска Desktop
  после холодного включения без USB. FEL сохраняется для восстановления.
